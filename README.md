# WealthOS

The operating system for building a better financial life.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Stripe Billing / Checkout
- Outlook Email
- Outlook Calendar
- Vercel

## MVP
Opportunity Intelligence: collect a user's financial/career profile, score opportunities, and produce an actionable wealth plan.

## Integrations
- Stripe: subscription billing boundary; live products/prices are intentionally not created yet.
- Outlook Email: planned customer lifecycle and intelligence communications.
- Outlook Calendar: planned planning sessions and scheduling workflows.
- Vercel: production deployment target.

## Development

```bash
npm install
npm run dev
```
